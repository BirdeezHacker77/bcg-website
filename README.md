# Bird Construction Group — Marketing Site

Static marketing website for **Bird Construction Group (BCG Inc)** — civil, commercial, and residential construction.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4
- React Router (client-side)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Contact form

`src/pages/Contact.tsx` defaults to a **mailto** fallback (`bids@birdconstruction.group`).  
Set `FORMSPREE_ENDPOINT` in that file to a Formspree URL when ready.

## Brand assets

Logo: `public/bcg-logo.png`

Project photography on the site is illustrative (Unsplash) until client case studies are provided.
